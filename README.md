## About the project

**Kflix** is an Android TV and mobile app that provides a user interface for accessing publicly available streaming content from various third-party providers.

### 🔄 What is Kflix?

- **Open Source**: Fully open-source and ad-free
- **Educational Purpose**: Designed for educational and personal use only
- **Multi-Provider**: Aggregates content from multiple third-party providers
- **OTA Updates**: Built-in in-app update system

### Features

- Open-source and ad-free interface
- Aggregates content from multiple third-party providers
- No account required for the app interface
- Educational and personal use only
- Optimized UI & UX
- Multiple providers
- Resume from last playback position
- In-app update (OTA)
- Profile system with multi-user support
- Parental controls

### Built with

- [Android Studio](https://developer.android.com/studio)
- [Kotlin](https://kotlinlang.org)
- [Retrofit](https://square.github.io/retrofit)
- [ExoPlayer](https://exoplayer.dev)
- Leanback
- Coroutines
- MVVM Architecture
- Android Architecture Components


## Getting started

### Prerequisites

Install [Android Studio](https://developer.android.com/studio)

### Setup

1. Clone the project to your local machine

```bash
git clone https://github.com/kaidencrawford22-source/Kfilx.git
```

2. Open the project in Android Studio

## Development

1. Select the device that you want to run the app
2. Click **Run**
